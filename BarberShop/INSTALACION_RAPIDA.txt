GUÍA RÁPIDA DE INSTALACIÓN - BarberShop
========================================

INSTRUCCIONES PARA COMPAÑEROS (Paso a Paso)
============================================

1. REQUISITOS PREVIOS (Instalar antes de empezar)
   ✓ Node.js 18+: https://nodejs.org/
   ✓ Python 3.10+: https://www.python.org/
   ✓ PostgreSQL 15+: https://www.postgresql.org/
   ✓ Git: https://git-scm.com/

2. CLONAR REPOSITORIO
   $ git clone https://github.com/DiegoSosaRam/BarberShopFrontend.git
   $ cd BarberShopFrontend/BarberShop

3. CONFIGURAR BASE DE DATOS (PostgreSQL)
   Ejecutar en PowerShell/CMD:
   
   $ psql -U postgres
   
   Luego copiar y ejecutar:
   
   CREATE DATABASE barbershop;
   CREATE USER barbershop_user WITH PASSWORD 'barbershop123';
   ALTER ROLE barbershop_user SET client_encoding TO 'utf8';
   ALTER ROLE barbershop_user SET default_transaction_isolation TO 'read committed';
   ALTER ROLE barbershop_user SET timezone TO 'UTC';
   GRANT ALL PRIVILEGES ON DATABASE barbershop TO barbershop_user;
   \q

4. CONFIGURAR BACKEND (Python/Django)
   
   $ cd backend
   
   # Crear entorno virtual
   $ python -m venv venv
   
   # Activar entorno virtual (Windows)
   $ venv\Scripts\activate
   
   # Instalar dependencias
   $ pip install -r requirements.txt

5. CREAR ARCHIVO .env (Backend)
   
   Crear archivo: backend/.env
   Copiar contenido:
   
   SECRET_KEY=your-secret-key-here
   DEBUG=True
   ALLOWED_HOSTS=localhost,127.0.0.1
   
   DB_ENGINE=django.db.backends.postgresql
   DB_NAME=barbershop
   DB_USER=barbershop_user
   DB_PASSWORD=barbershop123
   DB_HOST=localhost
   DB_PORT=5432
   
   CORS_ALLOWED_ORIGINS=http://localhost:8100,http://127.0.0.1:8100
   JWT_SECRET=your-jwt-secret-here

6. EJECUTAR MIGRACIONES Y SETUP
   
   # Desde backend/:
   $ python manage.py migrate
   
   # Ejecutar script SQL inicial
   $ psql -U barbershop_user -d barbershop -h localhost < sql/setup.sql
   
   # Crear superusuario (admin)
   $ python manage.py createsuperuser
   Ingresa:
   - Username: admin
   - Email: admin@barbershop.com
   - Password: (elige uno)

7. EJECUTAR BACKEND (Terminal 1)
   
   # Desde backend/:
   $ python manage.py runserver 0.0.0.0:8000
   
   Espera a ver: "Starting development server at http://127.0.0.1:8000/"

8. EJECUTAR FRONTEND (Terminal 2)
   
   # Desde raíz del proyecto:
   $ npm start
   
   O si está instalado Ionic:
   $ ionic serve
   
   Espera a ver: "Compiled successfully"

9. ACCEDER A LA APLICACIÓN
   
   ✓ Frontend: http://localhost:4200
   ✓ Admin Django: http://localhost:8000/admin/
   ✓ API: http://localhost:8000/api/

10. USUARIOS DE PRUEBA
    
    Admin:
    - Usuario: admin
    - Contraseña: (la que elegiste en paso 6)
    
    Puedes crear más usuarios desde Django admin.

PROBLEMAS COMUNES
=================

❌ "psycopg2 not found"
✓ Solución: pip install psycopg2-binary

❌ "Port 8000 already in use"
✓ Solución: python manage.py runserver 8001

❌ "CORS error en frontend"
✓ Solución: Verificar que apiUrl en environments/environment.ts sea correcto
   Debe ser: apiUrl: 'http://127.0.0.1:8000/api'

❌ "404 Not Found en API"
✓ Solución: Verificar que ejecutaste: psql -U barbershop_user -d barbershop < backend/sql/setup.sql

❌ "Connection refused"
✓ Solución: Verificar que PostgreSQL está ejecutándose
