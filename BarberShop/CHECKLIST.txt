COMANDOS RÁPIDOS PARA COMPAÑEROS
=================================

Activar virtual env:
$ venv\Scripts\activate

Ejecutar backend:
$ python manage.py runserver 0.0.0.0:8000

Ejecutar frontend:
$ npm start

Setup inicial (UNA VEZ):
$ python manage.py migrate
$ psql -U barbershop_user -d barbershop < backend/sql/setup.sql

Crear admin:
$ python manage.py createsuperuser
